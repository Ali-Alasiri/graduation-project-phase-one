# A7 – Problem Statement

## The Problem

Most people today own several devices at the same time: a smartphone, a laptop, a desktop computer, and often a tablet.  
The same photos, documents, videos and files are frequently stored on more than one of these devices. This creates three practical problems:

1. **Wasted storage** – Identical or very similar files occupy space on every device.
2. **Difficulty finding files** – A user often does not remember which device holds the latest version of a document or photo.
3. **Fragmented experience** – Moving a file, copying text, or controlling one device from another requires different apps, cables, or cloud services.

Current solutions only solve small parts of this problem:
- File-transfer apps (such as LocalSend) move files one by one.
- Folder-sync tools (such as Syncthing) keep selected folders identical but do not help with search or duplicates.
- Phone–PC apps (such as KDE Connect) offer clipboard and notifications but do not understand the content of files across all devices.
- Cloud services solve the problem by uploading everything to the internet, which raises privacy concerns, requires a constant connection, and still leaves the user without a unified local view.

There is no single local system that:
- connects all of a user’s devices over the local network without the internet,
- understands the files stored on every device,
- detects exact and near-duplicate files,
- provides one search across all devices (even when some are offline),
- and offers useful cross-device features such as password management, clipboard sharing, screen sharing and an extra display.

## Who is affected

This problem affects any person who regularly uses more than one device:
- university students who work on a laptop and a phone,
- employees who switch between a work computer and a personal laptop,
- content creators who edit photos and videos on several machines,
- families that share files between phones, tablets and home computers.

The more devices a person owns, the more fragmented and inefficient their digital life becomes.

## Summary

The core problem is the lack of a unified, private, offline-capable assistant that can see and manage the files and data across all of a user’s devices. Existing tools either require the cloud or address only one narrow need. Our project aims to fill this gap.
